## Document 1: Master Research Specification & Theoretical Blueprint

Project Title: Diversity as a Defense Against Misinformation in LLM Societies
Subtitle: Studying Information Propagation, Collective Intelligence, and Resilience in Multi-Agent Ecosystems
Version: 1.0 (Formal Research Specification)
Target Venues: NeurIPS / ICLR / ICML Workshops (AI Safety & Multi-Agent Systems Tracks), COLM, ACL Findings
Target Timeline: 8 Weeks (Targeting ArXiv release & Fall 2027 Master’s Application Portfolio)

### 1. Abstract & Executive Summary

As autonomous Large Language Models (LLMs) transition from isolated conversational assistants into interconnected multi-agent ecosystems, information is increasingly generated, transmitted, and consumed directly between AI systems without human oversight. This fundamental shift introduces novel network-level failure modes, including cascading hallucinations, false consensus formation, authority-induced bias, and synthetic echo chambers.
Current evaluation paradigms focus almost exclusively on single-agent capability benchmarks (e.g., coding, reasoning, retrieval). This research establishes a standardized framework for measuring information diffusion, belief persistence, and epidemiological resilience within multi-agent LLM societies.
We formalize and test the Functional Diversity Defense Hypothesis: that architectural and inductive heterogeneity across interacting agents acts as a systemic immunological defense against the propagation of misinformation, outperforming scale-matched homogeneous populations.

### 2. Theoretical Foundations & Mathematical Formulation

We model an artificial AI society as a dynamic, discrete-time communicative directed graph.

#### 2.1 Graph & Agent Definitions

Let the AI society be represented by the graph G = (V, E, Θ), where:
V = {A1, A2, ..., AN} is the set of N autonomous LLM agents.
E ⊆ V × V represents directed communication channels. The set Nin(i) = {Aj | (Aj, Ai) ∈ E} denotes the incoming neighbors of agent Ai.
Θ = {θ1, θ2, ..., θN} assigns model parameters θi ∈ M to each agent Ai, drawn from a pool of distinct model families M (e.g., Llama-3, Qwen-2.5, Mistral, Gemini).

#### 2.2 System Functional Diversity H(Θ)

Rather than parameter variance, we define functional diversity as the average pairwise Jensen-Shannon (JS) divergence of output token distributions across a reference task suite X:
H(Θ) = [ 2 / (N · (N - 1)) ] · ∑i=1..N ∑j=i+1..N DJS( Pθi(Y | X) || Pθj(Y | X) )

#### 2.3 Context Memory Operator Mφ

To prevent context window saturation and model recency biases, the context window Ci(t) of agent Ai at timestep t is updated via a bounded memory operator Mφ with a strict token budget K:
Ci(t+1) = Mφ( Ci(t) ⊕ [ ⨂j ∈ Nin(i) mj(t) ], K )
where mj(t) ~ Pθj(· | Cj(t)) is the stochastic message generated by neighbor Aj at time t.

#### 2.4 Dual-Probe Belief State Extraction Bi(t)(s)

For a proposition s ∈ S, an agent’s internal belief state Bi(t)(s) ∈ [0, 1] combines token logit probabilities with multi-prompt verbal consistency to avoid single-probe calibration errors:
Bi(t)(s) = α · σ( log Pθi("True" | Ci(t), s) - log Pθi("False" | Ci(t), s) ) + (1 - α) · (1 / M) ∑m=1..M I[ Probem(Ci(t), s) = "True" ]
where σ is the sigmoid function, α ∈ [0, 1] is a weighting hyperparameter, and Probem represents verbalized binary queries across M paraphrased templates.

### 3. Formal Hypotheses

H1 (Functional Diversity Defense): For a fixed total parameter count, populations with high functional diversity (H(Θ) > τ) exhibit a significantly lower asymptotic misinformation infection rate I∞ than homogeneous populations (H(Θ) = 0):
E[ I∞ | H(Θ) > τ ] < E[ I∞ | H(Θ) = 0 ]
H2 (Topology-Induced Bimodal Polarization): Clustered, small-world topologies (GWS) foster localized belief clusters leading to high global belief variance, whereas random graphs (GER) rapidly converge to uniform global consensus:
E[ BPI(T) | GWS ] > E[ BPI(T) | GER ]
H3 (Linguistic Certainty Super-Spreaders): Messages generated with high stylistic certainty (Sj) exert an amplified belief shift ΔBi(t+1) on receiving neighbors, independent of factual correctness:
∂ E[ ΔBi(t+1) ] / ∂ Sj > 0    ∀ Aj ∈ Nin(i)
H4 (Critical Misinformation Tipping Point ρ*): There exists a critical seeding density threshold ρ* ∈ (0, 1) of infected agents above which the network's Truth Retention Rate non-linearly collapses to zero as t → ∞.

### 5. Statistical Analysis Pipeline

To evaluate the empirical trajectories generated by the simulation engine, we implement three primary statistical evaluations:
Two-Way ANOVA (for H1): Tests the main effects and interaction between Population Type (Homogeneous vs. Heterogeneous) and Fact Tier (Grounded, Weak Prior, Reasoning Hook) on the final Truth Retention Rate (TRR) at α = 0.01.
Two-Sample Kolmogorov-Smirnov Test (for H2): Compares the final empirical belief distributions P(B(T)) of Watts-Strogatz small-world networks against Erdős–Rényi random networks to prove bimodal polarization.
Linear Mixed-Effects Model (for H3): Regresses neighbor belief changes ΔBi(t+1) against message certainty scores Sj, incorporating model architecture family as a random intercept effect.
